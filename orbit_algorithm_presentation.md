# Алгоритмы расчета орбиты и минимального расстояния

## Общее описание системы

Система предназначена для определения орбитальных параметров комет по наблюдениям и расчета момента и расстояния ближайшего сближения с Землей. 

Проект состоит из нескольких микросервисов:
- Backend сервис (FastAPI) - REST API для взаимодействия с клиентами
- Calculation сервис - выполняет сложные астрономические расчеты
- Notification сервис - отправляет уведомления пользователям
- Redis - используется как очередь задач
- MinIO - хранение изображений наблюдений
- PostgreSQL - основная база данных

## Алгоритм расчета орбиты

### Методология
Используется метод наименьших квадратов для определения орбитальных элементов по наблюдениям прямого восхождения (RA) и склонения (Dec) во времени.

### Этапы расчета
1. **Подготовка данных**: 
   - Проверка наличия минимум 3 наблюдений
   - Валидация формата данных наблюдений
   - Получение положений Земли в моменты наблюдений (эфемериды DE440S)

2. **Оптимизация параметров орбиты**:
   - Используется `scipy.optimize.least_squares`
   - Целевая функция: минимизация разницы между наблюдаемыми и расчетными RA/Dec
   - Орбитальные элементы: большая полуось (a), эксцентриситет (ecc), наклонение (inc), долгота восходящего узла (raan), аргумент перицентра (argp), истинная аномалия (nu)

3. **Физическая валидация**:
   - Проверка допустимых диапазонов параметров
   - Обработка эллиптических и гиперболических орбит
   - Корректное вычисление времени перигелия

### Используемые библиотеки
- `poliastro` - для моделирования орбит
- `astropy` - для астрономических расчетов и координат
- `scipy` - для оптимизации

## Алгоритм расчета минимального расстояния

### Методология
Дискретизация временного интервала с последующим поиском минимума расстояния между кометой и Землей.

### Этапы расчета
1. **Подготовка временного диапазона**:
   - По умолчанию: от текущего времени до следующего года
   - Возможность задания пользователем

2. **Расчет траектории**:
   - Использование ранее рассчитанных орбитальных элементов
   - Распространение орбиты на все временные точки

3. **Поиск минимума**:
   - Вычисление векторов положения кометы и Земли
   - Расчет евклидова расстояния между ними
   - Поиск минимального значения

## Особенности реализации

### Точность расчетов
- Использование высокоточных эфемерид DE440S
- Корректная обработка цикличности прямого восхождения (0-360°)
- Учет геоцентрического положения наблюдателя

### Обработка ошибок
- Проверка входных данных
- Обработка сбоев оптимизации
- Graceful degradation при ошибках расчета

### Производительность
- Асинхронная обработка задач через Redis Streams
- Кэширование промежуточных результатов
- Оптимизированные матричные операции NumPy

## Возможные улучшения

### Алгоритм расчета орбиты
1. Адаптивное начальное приближение вместо фиксированного
2. Механизм обнаружения и исключения выбросов в наблюдениях
3. Использование более продвинутых методов оптимизации (например, дифференциальная эволюция)

### Алгоритм расчета минимального расстояния
1. Адаптивная дискретизация с увеличенной плотностью вблизи минимума
2. Использование градиентных методов для поиска экстремума
3. Многомерная оптимизация с учетом неопределенности орбитальных параметров

## Заключение

Разработанные алгоритмы обеспечивают корректное определение орбитальных параметров комет и расчет их сближения с Землей. Система готова к использованию и может быть расширена для повышения точности и производительности.
