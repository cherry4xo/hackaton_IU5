# Алгоритмы расчета орбиты и минимального расстояния
## Краткая презентация для жюри

---

## Общее описание системы

Система предназначена для:
- Определения орбитальных параметров комет по наблюдениям
- Расчета момента и расстояния ближайшего сближения с Землей

Архитектура:
- Микросервисы (Backend, Calculation, Notification)
- Redis (очередь задач)
- PostgreSQL (база данных)
- MinIO (хранение изображений)

---

## Алгоритм расчета орбиты

### Методология
- Метод наименьших квадратов
- Оптимизация орбитальных элементов по наблюдениям RA/Dec

### Этапы
1. Подготовка данных (минимум 3 наблюдения)
2. Получение положений Земли (эфемериды DE440S)
3. Оптимизация параметров орбиты (scipy.optimize.least_squares)
4. Физическая валидация и вычисление времени перигелия

---

## Алгоритм расчета минимального расстояния

### Методология
- Дискретизация временного интервала
- Поиск минимума расстояния между кометой и Землей

### Этапы
1. Подготовка временного диапазона
2. Распространение орбиты на временные точки
3. Вычисление векторов положения кометы и Земли
4. Поиск минимального евклидова расстояния

---

## Используемые технологии

### Библиотеки Python
- `poliastro` - моделирование орбит
- `astropy` - астрономические расчеты
- `scipy` - оптимизация
- `numpy` - численные операции

### Точность
- Эфемериды DE440S (высокая точность)
- Корректная обработка цикличности RA (0-360°)

### Обработка ошибок
- Проверка входных данных

### Производительность
- Асинхронная обработка через Redis Streams
